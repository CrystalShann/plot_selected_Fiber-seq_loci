Introduction

selectFiberseqLociWorkflow is a native R package for analyzing processed Fiber-seq tracks at selected loci. Analysis runs directly in R. Regions use GRanges; each locus is a RangedSummarizedExperiment with genomic positions in rows and individual reads in columns. This vignette uses the same ALAS1 region and two tutorial LCL samples for both clustering choices.

The bundled data contain up to 100 full-span reads per sample per region, with complete matching m6A, nucleosome, TF-footprint and FIRE records. The small subset has 18 full-span reads at ALAS1 and 16 at PRDX1. It demonstrates usage and numerical consistency; it is not a biological replicate study. The data provenance and reproducible subset-generation script accompany the package. The example files are a subset of the actual AL6 and AL8 LCL tracks.

This tutorial executes all ten public functions. For a categorized guide with short examples, see Function reference and tutorials (vignette("function-reference", package = "selectFiberseqLociWorkflow")).

make_sample_sheet() Sample table or TSV Validated DataFrame of sample paths and explicit formats

Subsetting keeps read metadata, alignment ranges and footprints aligned with assay columns. Footprints describe the retained read within the original locus; row subsetting does not clip these stored intervals. Original QC, parameters and the cluster graph remain in metadata as run provenance. locus_profile() recalculates fractions for the current columns.

Unclustered views

Rows in the heatmap follow sample-sheet order, alignment start and read ID. The heatmap displays reads vertically and positions horizontally even though the underlying experiment uses the standard features-by-observations layout. The sample strip is farthest left; clustered views place the cluster strip next to it. Coordinate ticks and the orange dashed TSS marker follow the original plotting tutorial. Sample colors follow the sample sheet consistently across all read panels.

ComplexHeatmap::draw(plot_locus(unclustered, "heatmap"))

The pooled fraction divides by all full-span reads, including zero-call reads. Grey shows observed-position fractions; the blue curve uses the tutorial 10-bp sliding-window mean. The dashed line marks the supplied TSS.

By default, optional tracks use nucleosomes of 130-160 bp and TF footprints in [10,30), [40,60), or [60,80) bp. FiberHMM TF blocks require a score of at least 50. The footprint figure stacks the accessibility profile, blue m6A reads, and overlaid FIRE/nucleosome/TF tracks, with relative panel heights 2:6:6. FIRE is orange, nucleosomes are dark blue, and the three TF size classes are purple, magenta and cyan. Both read panels include the same sample-first annotations and read order as the heatmap.

TF length classes can be changed with analyze_loci(tf_length_ranges = list(c(30, 39), c(80, 120)), ...), using inclusive bounds. Use tf_length_ranges = NULL to retain all positive lengths. This applies to both FiberHMM BED15 and custom BED6 TF inputs.

A supplied footprint track with no retained calls raises the warning no footprints called in the selected region; the analysis still completes.

Analyze the same locus with clustering

Clustering uses observed m6A positions, Manhattan distances, a nearest-neighbor graph and Leiden communities. It does not change the input read set, sparse assay, pooled denominators or unclustered plots. The seed and all parameters are saved with the experiment. Exact pairwise distances require memory quadratic in the number of reads, so select suitably sized loci and datasets.

clustered <- analyze_loci(samples, alas1, clustering = TRUE,
    window_size = 0, k_neighbors = 10, resolution = 1, seed = 1)[["ALAS1"]]
stopifnot(identical(assay(unclustered), assay(clustered)),
    identical(colnames(unclustered), colnames(clustered)),
    identical(locus_profile(unclustered), locus_profile(clustered)))
table(colData(clustered)$sample_label, colData(clustered)$cluster)

Cluster plots only reorder reads or split profile denominators by existing cluster assignments. If a locus has fewer than three reads or two occupied features, clustering is skipped with a reason in metadata.

Choose bin size, nearest neighbors and resolution

These are arguments to analyze_loci(); edit their values when starting an analysis. The current defaults are unchanged:

Argument Default Meaning
window_size 0 No binning; cluster using individual observed m6A sites. A positive integer uses that bin width in bp.
k_neighbors 10 Number of Manhattan nearest neighbors per read, capped at the number of reads minus one.
resolution 1 Nonnegative Leiden resolution; larger values generally favor finer partitions.
seed 1 Reproducible random seed for Leiden clustering.

With binning, windows start at the selected locus’s first base. A read’s feature is its mean call across sites observed in any retained read within that bin. Empty bins do not contribute clustering features. The underlying assay and heatmap stay at single-base resolution. smoothing_bp = 10 is a separate setting for the profile curve, not the clustering bin width.

For example, use 50-bp bins, five neighbors and resolution 0.5. These values are illustrative settings for the small dataset, not optimized parameters.

custom <- analyze_loci(samples, alas1, clustering = TRUE,
    window_size = 50, k_neighbors = 5, resolution = 0.5,
    seed = 1)[["ALAS1"]]
metadata(custom)$parameters[c("window_size", "k_neighbors", "resolution")]
#> $window_size
#> [1] 50
#> 
#> $k_neighbors
#> [1] 5
#> 
#> $resolution
#> [1] 0.5
metadata(custom)$clustering$params$k_eff
#> [1] 5
table(colData(custom)$sample_label, colData(custom)$cluster)
#>      
#>       cluster1

# Binning and clustering parameters do not change the stored m6A assay
# or the pooled profile and its full-span-read denominator.
stopifnot(identical(assay(unclustered), assay(custom)),
    identical(locus_profile(unclustered), locus_profile(custom)))
plot_locus(custom, "profile", clustered = TRUE)

For clustering = FALSE, window_size, k_neighbors and resolution do not affect the analysis. To change a fitted partition, call analyze_loci() again with the desired settings; plot_locus() displays an existing result.

Export and reload

Save both runs to separate, new directories under one output folder. The run without clustering writes only unclustered/ panels. The run with clustering writes both unclustered/ and clustered/ panels alongside the complete Bioconductor object. The unclustered views remain independent of clustering parameters. RDS files preserve the choice and parameters for later plotting.

write_locus_results(clustered, file.path(output, "with-clustering"))

Within each ALAS1/ directory, locus.rds is the complete experiment; m6a_matrix.rds contains only the sparse assay; reads.tsv, qc.tsv and region.tsv describe the reads and input region. Each view contains m6a_heatmap.pdf, aggregate_m6a_profile.pdf, footprint_tracks.pdf, accessibility_profile.tsv, read_order.tsv and manifest.tsv. The clustered view also contains assignments.tsv and edges.tsv. For persistent results, replace tempfile() with your own output directory.

User data and plant annotations

Create a sample sheet with make_sample_sheet(data.frame(...)). Required columns are sample_name, m6a and m6a_format; optional tracks have their own explicit format columns. Paths can use {sample_name} and {chr} templates. Use bgzip-compressed tracks with adjacent tabix indexes and exact matching contig names from the same genome assembly. The package expects processed tracks; it does not call fibertools or FiberHMM itself.

prepare_regions() accepts GRanges, BED files, one-based inclusive coordinate strings, coordinate tables with declared conventions, or GTF/GFF3 transcript annotations. Ordinary annotation extraction retains distinct TSSs and does not require canonical transcripts. Promoter flanks default to 1,000 bp.

    package = "selectFiberseqLociWorkflow")
